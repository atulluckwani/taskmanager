Frontend Documentation

Complete guide to the React frontend application

Overview

The frontend is a modern React application that provides a user-friendly interface for managing tasks. It features a responsive design, smooth animations, and real-time updates.

ℹ️ Frontend Running At: http://localhost:3000

Project Structure

Components

📝 TaskForm Component

File: src/components/TaskForm.js

Purpose: Handles task creation with input for title, description, due date, and priority.

Features:
  • Text input for task title (required)
  • Textarea for task description (optional)
  • Date picker for setting due dates
  • Dropdown selector for priority levels (Low, Medium, High)
  • Form validation and submission handling
  • Loading state during form submission
Props:
  • onAddTask(taskData) - Callback function when form is submitted
  • loading - Boolean to disable form during submission
Styling:

Modern form design with glass-morphism effect, smooth transitions, and responsive layout.

✅ TaskItem Component

File: src/components/TaskItem.js

Purpose: Displays individual task with completion checkbox, edit, and delete functionality.

Features:
  • Checkbox for marking tasks as complete/incomplete
  • Display task title, description, priority, and due date
  • Color-coded priority badges (Low=Green, Medium=Orange, High=Red)
  • Visual indicators for overdue tasks
  • Task timestamps (created and updated)
  • Edit mode for updating task details
  • Delete button with confirmation
  • Completed state styling with strikethrough
Props:
  • task - Task object to display
  • onToggle(taskId) - Callback for completion toggle
  • onDelete(taskId) - Callback for task deletion
  • onUpdate(taskId, updates) - Callback for task updates
Styling:

Card-based layout with hover effects, smooth animations, and responsive design.

📋 TaskList Component

File: src/components/TaskList.js

Purpose: Container component for displaying filtered list of tasks.

Features:
  • Displays array of TaskItem components
  • Empty state message when no tasks match filter
  • Smooth animations for task list
  • Context-aware empty messages for different filters
Props:
  • tasks - Array of task objects to display
  • onToggle(taskId) - Callback for completion toggle
  • onDelete(taskId) - Callback for deletion
  • onUpdate(taskId, updates) - Callback for updates
  • filter - Current filter type (all, active, completed)
  • emptyMessage - Message to display when list is empty
Styling:

Flex layout with fade-in animations and bounce effects.

🎨 App Component

File: src/App.js

Purpose: Main application component managing state and API communication.

Features:
  • State management for tasks and filter selection
  • API communication with backend
  • Error handling and display
  • Task statistics display
  • Filter tabs for All, Active, and Completed tasks
  • Header with task counters
  • Local storage backup functionality
  • Gradient background with animated blobs
State Variables:
  • tasks - Array of all tasks
  • filter - Current filter (all, active, completed)
  • loading - Boolean for loading state
  • error - Error message if API call fails
  • stats - Task statistics object
Handlers:
  • handleAddTask(taskData) - Create new task
  • handleToggleTask(taskId) - Toggle completion
  • handleDeleteTask(taskId) - Delete task with confirmation
  • handleUpdateTask(taskId, updates) - Update task details

API Service Layer

File: src/services/api.js

The API service provides a centralized interface for all backend communication using Axios.

Available Methods

Method Function Description
getAllTasks() GET /api/tasks Fetch all tasks from server
getFilteredTasks(completed, priority) GET /api/tasks?filters Fetch tasks with filters applied
getTask(id) GET /api/tasks/{id} Fetch a single task by ID
createTask(taskData) POST /api/tasks Create a new task
updateTask(id, taskData) PUT /api/tasks/{id} Update an existing task
deleteTask(id) DELETE /api/tasks/{id} Delete a task
toggleTask(id) POST /api/tasks/{id}/toggle Toggle task completion status
getStats() GET /api/stats Fetch task statistics
healthCheck() GET /api/health Check backend health status

Running the Frontend

Prerequisites

  • Node.js 14.0+
  • npm 6.0+

Installation & Running

cd frontend
npm install                    # Install dependencies
npm start                      # Start development server
npm run build                  # Build for production
npm test                       # Run tests

Development Server

The development server runs on http://localhost:3000 with hot module reloading. Changes to component files are reflected immediately in the browser.

Troubleshooting

Common Issues

Port 3000 Already in Use

Either kill the existing process or set a different port:

set PORT=3001 && npm start    # Windows
PORT=3001 npm start             # macOS/Linux

Module Not Found Errors

Clear node_modules and reinstall:

rm -r node_modules package-lock.json
npm install

API Connection Issues

Ensure the backend is running on port 8000 and check the .env file has correct API URL.

CORS Errors

Backend CORS is already configured. If issues persist, check that both servers are running.

Performance Optimization

  • Code Splitting: React automatically handles code splitting with react-scripts
  • Lazy Loading: Images and heavy components can be lazy-loaded
  • State Management: Efficient React hooks usage for state management
  • API Caching: Local storage backup prevents unnecessary API calls
  • CSS Optimization: Scoped component CSS with no global conflicts
