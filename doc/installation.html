Quick Setup (Automated)

✨ Recommended approach for beginners

Step 1: Install Python and Node.js

Windows

Python:

  1. Visit python.org
  2. Download Python 3.12+ for Windows 64-bit
  3. Run installer
  4. Important: Check "Add Python to PATH"
  5. Click Install

Node.js:

  1. Visit nodejs.org
  2. Download LTS version for Windows
  3. Run installer and follow prompts

macOS

Using Homebrew (Recommended):

# Install Homebrew if not already installed /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # Install Python and Node.js brew install python@3.12 node

Or download installers:

  • Python: python.org
  • Node.js: nodejs.org

Linux

Ubuntu/Debian:

sudo apt-get update sudo apt-get install python3.12 python3.12-venv python3-pip sudo apt-get install nodejs npm

Fedora/RedHat:

sudo dnf install python3.12 python3.12-devel sudo dnf install nodejs npm

Step 2: Verify Installation

Open a terminal and run:

python --version node --version npm --version

You should see version numbers for all three.

Step 3: Run Setup Script

Navigate to the project directory and run:

cd c:\Workspace\taskmanager .\setup.bat

This script will automatically:

  • Create Python virtual environment
  • Install backend dependencies
  • Install frontend dependencies
  • Provide instructions for running the app

Navigate to the project directory and run:

cd /path/to/taskmanager bash setup.sh

This script will automatically:

  • Create Python virtual environment
  • Install backend dependencies
  • Install frontend dependencies
  • Provide instructions for running the app

Manual Setup

ℹ️ For advanced users who prefer manual control
1 Backend Setup

Open a terminal and navigate to the project:

cd c:\Workspace\taskmanager\backend # Windows cd /path/to/taskmanager/backend # macOS/Linux

Create a virtual environment:

python -m venv venv

Activate the virtual environment:

venv\Scripts\activate
source venv/bin/activate

Install Python dependencies:

pip install -r requirements.txt

Start the backend server:

python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
✅ Backend is ready! Visit http://localhost:8000
2 Frontend Setup

Open a new terminal and navigate to the frontend directory:

cd c:\Workspace\taskmanager\frontend # Windows cd /path/to/taskmanager/frontend # macOS/Linux

Install npm dependencies:

npm install

Start the development server:

npm start
✅ Frontend is ready! Visit http://localhost:3000

Troubleshooting

❌ "Python not found" or "npm not found"

Python and Node.js are not in your system PATH. Reinstall them and ensure "Add to PATH" is checked during installation. Then restart your terminal.

❌ Port 3000 or 8000 already in use

Another application is using the port. You can either:

  • Kill the existing process
  • Use a different port: PORT=3001 npm start
❌ "Module not found" errors

Clear node_modules and reinstall:

cd frontend rm -r node_modules package-lock.json npm install
❌ CORS errors when loading tasks

Ensure both backend and frontend are running:

  • Backend should show "Application startup complete"
  • Frontend should show "Compiled successfully!"
❌ Virtual environment issues (Python)

Delete the venv folder and recreate it:

cd backend rm -r venv python -m venv venv venv\Scripts\activate # Windows or source venv/bin/activate pip install -r requirements.txt
❌ Frontend shows blank/white screen

Open browser developer console (F12) and check for errors:

  • Check if backend is running at the correct URL
  • Check .env file has correct API_URL
  • Clear browser cache and reload

Environment Variables

Backend (.env)

ENVIRONMENT=development
DATABASE_PATH=tasks.json
DEBUG=true
API_PORT=8000

Frontend (.env)

REACT_APP_API_URL=http://localhost:8000
REACT_APP_ENV=development

These files are already configured in the project. Modify them only if you need different settings.

Production Deployment

Building for Production

Frontend:

cd frontend npm run build

This creates an optimized build in the build/ directory ready for serving with a static file server.

Backend:

pip install gunicorn gunicorn app.main:app --workers 4 --worker-class uvicorn.workers.UvicornWorker --bind 0.0.0.0:8000

Use proper environment variables for production and ensure HTTPS is enabled.
