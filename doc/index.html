Running the Application

Automatic Setup (Recommended):

cd c:\Workspace\taskmanager
.\setup.bat         # Windows
bash setup.sh       # macOS/Linux

Manual Setup:

Terminal 1 - Backend:

cd backend
python -m venv venv
venv\Scripts\activate    # Windows
source venv/bin/activate # macOS/Linux
pip install -r requirements.txt
python -m uvicorn app.main:app --reload

Terminal 2 - Frontend:

cd frontend
npm install
npm start

Access Points:

  • Frontend: http://localhost:3000
  • Backend API: http://localhost:8000
  • API Documentation: http://localhost:8000/docs

API Overview

The backend provides a comprehensive REST API for task management. All endpoints support JSON request/response format with CORS enabled.

GET /api/tasks

Retrieve all tasks with optional filtering by completion status or priority

POST /api/tasks

Create a new task with title, description, priority, and due date

PUT /api/tasks/{id}

Update an existing task with new information

DELETE /api/tasks/{id}

Delete a task permanently

POST /api/tasks/{id}/toggle

Toggle task completion status

GET /api/stats

Get task statistics (total, completed, active, completion rate)

For detailed API documentation, visit the Backend API Documentation page.
